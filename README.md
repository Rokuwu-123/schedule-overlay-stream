# Schedule Overlay Stream

Overlay stream yang menunjukkan jadwal stream kedepannya, tampilan bisa disesuaikan dengan keinginan sendiri, baik melalui code html atau css

Created by :
Rokkuwu
DekReza

## Programming Language

Bahasa pemrograman yang digunakan adalah JS dengan Express sebagai frameworknya. Untuk pengiriman data menggunakan websocket dari [Socket.io](https://socket.io/)

Package yang perlu diinstall :
```bash
npm i express crypto socket.io socket.io-client eslint ejs
```

Optional package :
```bash
npm i nodemon -g --save
```

## Installation

1. Kalian harus donwload dulu [NodeJS](https://nodejs.org/en/download) (pastikan versi LTS terbaru ya)
2. Clone repositori github ini
3. Buka CMD lalu arahkan ke folder project kalian dan ketikkan perintah :
```bash
npm install
```

## How To Run

1. Buka CMD lalu arahkan ke folder project kalian atau buka folder project kalian melalui VSCode kemudian buka terminal
2. Jalankan perintah
```bash
node server
```
3. Buka browser lalu ketik url :
```bash
localhost:3000
```
